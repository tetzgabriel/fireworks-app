# Vai ter fogos hoje?

A beautiful Flutter calendar app that shows you when and where to expect fireworks in Brazil.

## Features

- **Beautiful Calendar Interface:** Navigate through months with a sleek, dark-themed UI.
- **Event Highlights:** Dates with high probability of fireworks are clearly marked.
- **Event Details:** Tap on a date to see what's being celebrated (New Year's, Carnival, Festas Juninas, etc.).
- **Brazilian Localization:** Fully localized dates and descriptions in Portuguese.

## Getting Started

1.  **Prerequisites:** Ensure you have Flutter installed.
2.  **Clone the repository** (if applicable).
3.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
4.  **Run the app:**
    ```bash
    flutter run
    ```

## specialized Data

The app currently uses a hardcoded list of major Brazilian holidays known for fireworks. Future updates could include a real-time API or more regional events.
